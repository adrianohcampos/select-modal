SelectModal

Um <select> que abre em um <dialog> nativo com busca. Sem jQuery, sem Bootstrap. O botão Bootstrap recarrega esta página com bootstrap.css + select-modal-bootstrap.css.

Básico

Basta a classe select-modal.

Grupos, subtexto e limpar

<optgroup>, data-subtext e data-allow-clear.

Múltiplo

multiple + data-select-all + data-max-selections="5". Clique no contador para ver só os selecionados.

Ação "novo"

Opção com data-select-modal-action vira botão. Digite um nome que não existe e pressione Enter.

Modo dropdown

data-mode="dropdown": lista ancorada ao campo no desktop; no celular continua como modal. Foque o campo e digite uma letra.

Dados remotos

Opção source (função ou URL). Aqui uma API simulada com 400 ms de atraso e mínimo de 2 caracteres.

Criar digitando

data-allow-create: digite algo que não existe e pressione Enter.

Imagens e conteúdo próprio

data-image / data-icon na opção, ou a função renderOption.

Lista grande

20.000 opções: a lista é desenhada aos poucos conforme a rolagem.

Validação de formulário

required funciona com a validação nativa.

Tamanhos e desabilitado

data-size="sm|lg" e disabled.

API JavaScript

SelectModal.get(el) devolve a instância.

Dentro de outro dialog

O seletor empilha por cima de modais já abertos.

Novo pedido

Eventos

change, selectmodal:open, selectmodal:close, selectmodal:action e selectmodal:create.
